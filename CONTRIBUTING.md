# Contributing

Thanks for helping. A few rules keep Khylo calm and consistent:

1. **Open an issue first** for anything bigger than a small fix, so we can agree on the approach.
2. **Keep it Khylo.** Names, text and file names in user-facing places are about Khylo only.
3. **Test it.** Builds in Release must succeed and the existing tests must pass; add tests for new behaviour.
4. **No private details.** No addresses, usernames, keys or library contents in code, docs, tests or screenshots.
5. **Plain language** in anything people read: short, friendly, no jargon.
6. By contributing you agree your work is licensed under this repository's license.
